# Intro-to-GitHub

This repository was created as part of a Machine Problem assignment to learn the fundamentals of Git and GitHub — including creating repositories, uploading files, cloning, committing, and pushing changes from a local machine to a remote repository.

## Purpose

- Practice creating and managing a GitHub repository
- Learn how to clone a repository to a local machine
- Practice staging, committing, and pushing changes with Git
- Understand the relationship between a local Git repository and its remote counterpart on GitHub
