# Notes: Git and GitHub Basics

- **Git** is a version control tool installed locally; **GitHub** is a website that hosts Git repositories online and adds collaboration features.
- A **repository** stores a project's files along with the full history of changes.
- A **commit** is a snapshot of changes with a message explaining what was done.
- **Branches** let you work on new features without affecting the main codebase.
- **Pull requests** propose merging changes from one branch into another, usually with a review step.
- Typical local-to-remote workflow: `git clone` -> edit files -> `git add` -> `git commit` -> `git push`.
